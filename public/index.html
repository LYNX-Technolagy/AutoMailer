How it works

Three steps. No accounts, no database, no surprises.

01

Upload a JSON file

A top-level array of email strings. Anything invalid — a typo, a stray object, a duplicate — is skipped and reported. The rest still send.

["a@x.com", "b@y.com", "oops"]
02

Write your message

Subject and HTML body. The same message goes to every valid recipient, one email at a time with a 2-second gap.

03

Review the report

Per-recipient success, failure, or skipped. Failures don't stop the loop — you get the full picture at the end.

→

Get started

Get started

Runs on your machine in a few minutes. You'll need Node.js 20 or newer and a Gmail account with an App Password.

  1. 1

    Clone the repository

    Grab the code and install dependencies.

    git clone https://github.com/LYNX-Technolagy/AutoMailer.git
cd AutoMailer
npm install
  2. 2

    Run the setup script

    This prompts for a port and whether to enable dry-run mode, then writes a .env file with a generated session secret. You never edit .env by hand. 

    npm run setup
  3. 3

    Start the app

    Launch the server.

    npm run dev

    Open http://localhost:3000/app. Click Connect Gmail in the top-right — the modal walks you through generating an App Password, step by step.

Prefer to test without sending? Answer "yes" to dry-run when running npm run setup, or set DRY_RUN=true in .env. The whole flow runs, but no emails go out.
