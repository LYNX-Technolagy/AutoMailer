How it works

Three steps. No accounts, no database, no surprises.

01

Upload a JSON file

A top-level array of email strings. Anything invalid — a typo, a stray object, a duplicate — is skipped and reported. The rest still send.

["a@x.com", "b@y.com", "oops"]
02

Write your message

Subject and HTML body. The same message goes to every valid recipient, one email at a time with a 2-second gap.

03

Review the report

Per-recipient success, failure, or skipped. Failures don't stop the loop — you get the full picture at the end.
